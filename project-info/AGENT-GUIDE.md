# Multi-Agent Agent Guide

## Shared workflow

Before starting work:

1. Read `AGENTS.md` and `project-info/OVERVIEW.md`.
2. Check `project-info/TASKS.md` for ownership and avoid duplicating in-progress work.
3. State the task's files, acceptance criteria, and validation in `project-info/TASKS.md`.
4. Add durable implementation details to `project-info/DECISIONS.md`.

## Suggested ownership

- `index.html`: structure, controls, canvas containers, accessibility labels
- `style.css`: layout, visual system, responsive behavior, transitions
- `script.js`: presentation state, examples, DOM updates, canvas effects
- `project-info/`: requirements, ownership, decisions, and verification records

## Handoff format

Add or update a task entry with:

- Agent or owner
- Status: blocked, in progress, ready for review, or done
- Files
- Acceptance criteria
- Validation performed
- Follow-up or known limitations

Do not overwrite another agent's completed notes. Append a dated update instead.
